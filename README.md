# Chess

A complete chess game in a single HTML file — no dependencies, no build step,
no internet required. Open `index.html` in any browser and play against a
neural-network computer opponent.

## Features

- **5 difficulty levels** whose calculation time ramps from ~0.3s (Beginner)
  up to the full 1.5s (Master); easier levels also search shallower and play
  with deliberate randomness so they make beatable, human-like mistakes
- **Neural-network evaluation** — a small trained network scores positions
  (see below)
- A visible "thinking" indicator while the computer calculates
- Move sounds (synthesized, no audio files) with a mute toggle — captures and
  checks sound different
- Full chess rules: castling, en passant, pawn promotion (with piece picker),
  check, checkmate, stalemate, 50-move rule, threefold repetition, and
  insufficient material draws
- A celebration overlay when you win, with a Play New Game button
- Play as White or Black (board flips automatically)
- Legal move hints, last-move and check highlighting
- Move history, captured pieces, and material advantage display
- Undo button

## How it works

The engine uses a hand-written move generator (validated against standard
perft test positions) and a negamax search with alpha-beta pruning, MVV-LVA
move ordering, and iterative deepening within a per-level time budget.

Positions are scored by a small **neural network** (a multi-layer perceptron:
768 piece-on-square inputs → a 32-unit hidden ReLU layer → one score). Its
weights were trained offline by distillation: tens of thousands of positions
were generated by self-play and labeled with a shallow search of the engine,
then the network was fit by gradient descent (Adam) to reproduce those
evaluations. The trained weights are quantized and embedded directly in the
HTML, and the network runs entirely in your browser — no server, no API, no
cost. If the weights ever fail to load, the engine automatically falls back to
a classic material + piece-square-table evaluation.

The neural network is the *evaluator* (it judges how good a position is); the
search is the *planner* (it looks ahead through candidate moves). Together,
the difficulty mostly scales with how deep/long each level searches.
